# Медведи Ярославля

Интерактивный путеводитель по Ярославлю через городские скульптуры медведей. Проект рассказывает о истории, культуре и ремёслах города, используя больших медведей и маленьких медведиков как ориентиры на карте.

## Что внутри

- **5 тематических маршрутов** по Ярославлю — от обзорного до промышленного
- **Интерактивная карта** с точками остановок и пешеходными маршрутами
- **Лента слайдов** с описанием каждой остановки, связанная с картой
- **Чек-лист всех медведей** города с возможностью отмечать посещённых
- **Прогресс-бар** и сохранение отметок в localStorage
- **Адаптивная вёрстка** для телефонов, планшетов и десктопа

## Технологии

- **React** + **Vite**
- **Yandex Maps API v3** — карта, маркеры, маршруты
- **OSRM** — построение пешеходных маршрутов
- **localStorage** — сохранение прогресса посещений
